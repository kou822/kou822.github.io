Beecon プライバシーポリシー

最終更新日: 2026年10月14日 ・ English

本ポリシーは、Koichiro Yamashita(以下「当方」)が提供するiOSアプリ 「Beecon」(以下「本アプリ」)における、利用者情報の取り扱いについて定めるものです。 本アプリは、建物内で友人とはぐれた際に、事前に承認した相手との間でのみ位置を共有し、 相手を見つけるためのアプリです。

1. 収集する情報と利用目的

情報の種類利用目的
位置情報(GPS等による精密な位置) 友人とはぐれた際に、承認済みの相手の端末にのみあなたの位置を届け、 相手までの距離・方角・相対的な高さを表示するため。位置は端末間でエンドツーエンド暗号化され、 当方のサーバーは内容を読むことができず、保存もしません。距離等の計算は端末内で行います。
センサー情報(Bluetooth電波強度、UWB(近接測位)、気圧・モーション) 近くにいる友人までの距離・方角・階層(高さ)をより正確に推定するため。 これらは主に端末内で処理されます。
プッシュ通知トークン 「探されています」等のプッシュ通知を届けるため、配信先としてサーバーに保持します。 本アプリにアカウント・ユーザーIDはなく、氏名やメールアドレスも取得しません。
プッシュ通知の配信に伴う情報(Google が収集するもの): Firebase のインストール ID、配信の計測情報、 SDK の動作に関する診断情報(エラー・性能などの技術的な情報) プッシュ通知を届け、その配信状況を計測し、Firebase のサービスを維持・改善するため。 Firebase の SDK を通じて Google が直接収集し、Google のポリシーに従って取り扱われます。 広告の表示の有無にかかわらず、プッシュ通知を使うために必要です。 位置情報・友人関係・表示名は含まれません。
表示名(任意) 友人に自分を識別してもらうため。端末内に保存され、友人の端末へ暗号化して直接届きます(サーバーは読めません)。設定は任意です。
広告関連情報(Google が収集するもの): 端末の識別子(アプリ・開発者単位のもの)、IPアドレスとそこから推定されるおおよその地域、 表示された広告、アプリの起動やタップなどの操作情報、 クラッシュログ、起動時間・ハング率・電力消費などのパフォーマンス情報 本アプリ内に広告(Google AdMob)を表示し、その配信状況の計測・不正防止・サービス改善を行うため。 これらは広告 SDK を通じて Google が直接収集し、Google のポリシーに従って取り扱われます。 本アプリは非パーソナライズ広告を要求しますが、これは広告の選び方に関する設定であり、 上記の情報の収集そのものを止めるものではありません。 あなたの位置情報(GPS)・友人関係・表示名が広告のために使われたり Google に渡されたりすることはありません。 同意が必要な地域では、広告を表示する前に同意を確認します(アプリの 設定 → プライバシー から変更できます)。

2. 位置情報の共有範囲

あなたの位置情報が他の利用者に共有されるのは、あなたが事前に承認(招待の受諾)した友人が、 あなたを「探す」操作を行い、かつあなたがその都度または設定に基づき共有を許可した場合に限られます。 承認していない相手にあなたの位置が渡ることはありません。共有の可否は、アプリ内の「探される設定」 (オフ / 起動中のみ / いつでも)でいつでも変更でき、この設定はあなたの端末内にのみ保存され、端末自身が判断します。 友人関係もあなたの端末内にのみ保存され、当方のサーバーは誰と誰が友人かを把握しません。

3. 第三者への提供・外部サービス

本アプリは以下の外部サービスを利用します。各社の取り扱いは各社のポリシーに従います。

  • Google Firebase(プッシュ通知の配信)— Firebase プライバシー
  • Google AdMob(アプリ内広告の配信・計測)— Google 広告に関するポリシー

上記のほか、法令に基づく場合を除き、あなたの情報を第三者に提供・販売することはありません。

4. データの保存と削除

友人関係・暗号鍵・表示名・共有設定・通知履歴は端末内にのみ保存されます。 アプリの 設定 → プライバシー →「すべてのデータを削除」で、いつでもこれらを消去し、友人にも解除を伝えることができます。

本アプリを削除(アンインストール)すると友人関係は失効します。端末の仕組み上、暗号鍵などの一部が端末内の 保護領域に残る場合がありますが、本アプリを再びインストールした際には最初にそれらを消去するため、 以前の友人関係や共有設定が復活することはありません。バックアップからの復元や機種変更でも引き継がれません。 通知履歴は最新50件・30日分のみ保持します。

サーバーが保持するのは次のものだけです。

保持するもの保持期間
位置・探索の依頼などの暗号化されたメッセージ(メモリ上のみ。内容は当方も読めません) 相手が受け取るまで、最長30秒(定期的な消去処理の間隔を含め、遅くとも約1分以内)
表示名や共有設定の変更・友人の解除を伝える暗号化されたメッセージ(メモリ上のみ) 相手が受け取るまで、最長7日
通知の配信先(プッシュ通知トークンと、中身を推測できない宛先のハッシュ値) 最後に使われてから180日。友人を解除した時点でその宛先は削除されます
解除済みの宛先のハッシュ値(再利用を防ぐための記録)90日
招待コード(公開鍵と暗号化された情報)友人の追加が完了するまで、最長24時間

サーバーは位置情報の履歴を保存せず、暗号化されたメッセージをディスクに書き込みません。

5. お子様のプライバシー

本アプリに年齢による利用制限はありません。アカウント登録はなく、利用者の年齢・氏名・連絡先を尋ねることも収集することもありません。収集する情報は、年齢にかかわらず本ポリシーに記載したものだけです。お子様が利用する場合は、位置を共有する相手を保護者の方と一緒にご確認ください。

6. 本ポリシーの変更

本ポリシーは必要に応じて改定されることがあります。重要な変更はアプリ内または本ページで告知します。
